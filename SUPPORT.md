# Getting help with Concord Voice

| You want to... | Go here |
| :-- | :-- |
| Download the desktop app | [concordvoice.com/download](https://www.concordvoice.com/download) |
| Run your own server | [Self-hosting guide](https://www.concordvoice.com/self-hosting) and the [Self-Hosted wiki](https://github.com/Concord-Voice/Self-Hosted/wiki) |
| Learn the desktop app | [Desktop wiki](https://github.com/Concord-Voice/Desktop/wiki) |
| Check whether a problem is already known | [Known Issues](https://github.com/Concord-Voice/Feedback/issues/39) |
| Report a bug or ask for a feature | [Feedback](https://github.com/Concord-Voice/Feedback/issues/new/choose), or **Send Feedback** in the app |
| Ask a question or talk with other users | [r/ConcordVoice](https://www.reddit.com/r/ConcordVoice/) |
| Ask about your account, billing, or anything else | [contact-us@concordvoice.com](mailto:contact-us@concordvoice.com) |
| Ask about privacy or your data | [privacy@concordvoice.com](mailto:privacy@concordvoice.com) |
| Report a security vulnerability | [security@concordvoice.com](mailto:security@concordvoice.com). Never file it publicly. See the [security policy](SECURITY.md). |

We will never ask for your password, your backup codes, or your recovery key. Anyone who does is not us.
