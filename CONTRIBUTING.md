# Contributing to Concord Voice

Thanks for your interest in contributing to [Concord Voice](https://www.concordvoice.com)!

> [!NOTE]
> The app repositories ([Desktop](https://github.com/Concord-Voice/Desktop), [Self-Hosted](https://github.com/Concord-Voice/Self-Hosted), and [Mobile](https://github.com/Concord-Voice/Mobile)) are public. The hosted service and release operations stay private. This guide covers how we work across the organization; a repository's own `CONTRIBUTING.md` overrides it where present.

## Ways to contribute right now

- Join the conversation on [r/ConcordVoice](https://www.reddit.com/r/ConcordVoice/).
- File bugs and share feature ideas in the [Feedback repository](https://github.com/Concord-Voice/Feedback). Check the [Known Issues list](https://github.com/Concord-Voice/Feedback/issues/39) first.
- Report security issues privately. See [SECURITY.md](SECURITY.md).
- Support the project with a [paid plan](https://www.concordvoice.com/pricing), and help us spread the word.

## Working in our repositories

- **Branches:** `feature/…`, `fix/…`, `chore/…`, `docs/…`, `test/…`.
- **Commits:** follow [Conventional Commits](https://www.conventionalcommits.org/) with a bare type and no scope (`feat: …`, `fix: …`, `docs: …`), and reference the issue or PR where relevant.
- **Pull requests:** keep them focused, fill out the template, and make sure CI is green before requesting review. Update the docs in the same PR as the code they describe. Be kind and constructive in review.
- **Public files:** never name other comms products in code, comments, tests, commit messages, or docs. Describe the behavior instead.
- **AI tools:** allowed. Label AI-assisted commits with a `Co-Authored-By` trailer and follow our [AI policy](AI_POLICY.md).
- **Licensing:** contributions are accepted under the repository's license, the **Concord Voice Source License (CVSL 1.0)**, which converts to **AGPL-3.0-or-later on 2030-02-15**.

## Code of Conduct

All participation in our spaces is governed by our [Code of Conduct](CODE_OF_CONDUCT.md). Be excellent to each other.
